部屋の作成と現在の状態の取得は HTTP で行い，実際の対局は WebSocket で進めます。

## 進め方

1. `POST /rooms/new` で部屋を作り，`room_id` を受け取る。
2. `GET /rooms/{room_id}` で盤面とプレイヤーの一覧を取得する。
3. `GET /rooms/{room_id}/ws` で WebSocket に繋ぎ，以降はそちらでやり取りする。

対戦相手には部屋の URL を共有してもらい，同じように 2. から始めてもらいます。

## WebSocket

接続が確立すると，サーバーはまず Ping を送ります。クライアントが Pong を返すまで以降の処理は始まりません。

やり取りするメッセージは全てテキストフレームの JSON で，`{"t": <番号>, "c": <内容>}` という形をしています。`c` が無いメッセージもあります。
`t` の番号空間は向きごとに独立していて，同じ番号でも意味が違うことに注意してください。

| 向き                          | スキーマ                                              | 番号     |
| ----------------------------- | ----------------------------------------------------- | -------- |
| クライアント → サーバー       | `PlayerAction`                                        | 0〜3     |
| サーバー → 特定のクライアント | `Responses`                                           | 101〜104 |
| サーバー → 部屋にいる全員     | `RegisterRoomEvent` (`RoomEvent` に `i` を添えたもの) | 3〜5     |

部屋への配信には，イベントを起こしたプレイヤーの `public_id` が `i` として付きます。

### 参加と復帰

`JoinTeam` に成功すると `UserCreated` で `private_id` と `public_id` が返ります。
`private_id` は本人だけが持つ秘密の値で，これを `Resume` で示すと認証済みの状態になり，`LeaveTeam` と `Move` が使えるようになります。

接続が切れてもプレイヤーはすぐには消えず，60 秒の猶予があります。その間に繋ぎ直して `Resume` を送れば元のプレイヤーとして復帰できます。
猶予を過ぎていた場合は `SessionExpired` が返るので，`JoinTeam` からやり直してください。

### 切断される場合

| コード           | 理由            | 状況                                                                                   |
| ---------------- | --------------- | -------------------------------------------------------------------------------------- |
| 1007 (`INVALID`) | `Invalid Data`  | テキストフレーム以外を受け取った，または JSON を `PlayerAction` として解釈できなかった |
| 1013 (`AGAIN`)   | `Server Lagged` | 配信されるイベントの処理がクライアントに対して追いつかなくなった                       |
