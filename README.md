# numbers-game

チェッカーと独自の要素を組み合わせたオリジナルのボードゲームです。

## 実行

実行前に [Rust](https://www.rust-lang.org/) のインストールが必要です。

ゲームサーバー:

```
cargo r
```

## API ドキュメント

サーバーの起動中は http://localhost:3000/docs で Scalar を開けます。
OpenAPI の定義そのものは http://localhost:3000/openapi.json にあります。
